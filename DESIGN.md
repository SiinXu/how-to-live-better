# Visual system — Nocturne (v7)

Fancy-but-restrained reading UI for 《高性价比人生指南》. Replaces Ink & Paper (v6, judged too plain).

Borrowed craft from the UI resource hub:
- Aceternity UI — mouse-follow spotlight + glowing border on cards/rows, floating glass pill nav, masked grid-line backdrop.
- Magic UI — border-beam on the hero search, number ticker stats, dual-direction marquee (chapter questions), animated gradient text.
- Motion Primitives / React Bits — blur-up in-view reveal, spring sliding tab indicator, slow aurora glows.
- Cult UI / shadcn — tight tokens, hairline borders, mono numerals, kbd hints, compact pills.

- Palette: deep blue-black ink #07070b (not zinc) + iris/violet/aqua aurora accent; crisp white light mirror. Evidence A/B/C = mint/amber/slate dots.
- Home: centered hero, stats strip, marquee, 4 bento resource tiles, 3-col hairline chapter grid, notes, docs.
- Chapter: sticky sidebar (filters + rail nav with glowing active bar), glass sticky filter bar, compact entry panels with 说人话 highlight and cost/gain columns.
- Keep: 677 entries, filters, #e-1-16 deep links, CC BY 4.0 attribution. Respects prefers-reduced-motion.
