# Visual system — Quiet Luxury Docs (v4)

Reading site for 《高性价比人生指南》. Quiet luxury: refined, not neon, not parchment cosplay.

## Direction

| Keep | Change |
|---|---|
| Original card anatomy (`#e-1-16`), sidebar filters, evidence colors | Soft stone page + white elevated cards (hairline + soft shadow) |
| Cost/gain always visible, 来源 in `<details>` | Fixed 3.25em label column; values `break-word` (no mid-URL row blowups) |
| Deep links `#e-1-16` / `#/c/1/16` | Sources split into stacked citation cards; URL labels shortened |
| Content & filters untouched | Muted navy accent, solid mark (no gradient/glow), no spotlight hover |

## Non-goals

- Not Warm Editorial Paper (parchment + cinnabar + Instrument Serif)
- Not UI Hub electric cyan / neon glow
- Not changing entry text or evidence content
