# Visual system — Warm Editorial Paper (v2)

Restyle of HowToLiveBetter reading site. Deliberately **not** the UI Resource Hub palette (midnight ink + electric cyan).

## Inspiration (from UI Hub collected libraries)
| Source | What we took |
|---|---|
| **Refero** | Serif display headline, paper-white/cream canvas, ink primary button, search as hero object, quiet chrome |
| **Beautiful UI** | Numbered mono section labels (`01`), hairline rules, calm stage around content |
| **Linear** | Density + restraint: 13–14px UI, 1px hairlines, no glow, no gradient fills |
| **Mobbin** | Soft neutral plate under content; meta quiet; no chrome competing with reading |

## Palette
- **Light (default):** parchment `#f4efe6` / surface `#fffcf7` / mat `#ebe4d8`
- **Ink:** `#1c1712` / `#5c5348` / `#90867a`
- **Accent:** cinnabar terracotta `#b5472a` (one functional accent — badges, highlights, italic words)
- **Dark:** warm charcoal `#161310` / `#1e1a16`, accent `#e07a5f` — never cool black or cyan

## Type
- Display / hero / chapter titles: Instrument Serif (+ Songti CJK)
- UI / body: Geist
- Labels / counts: Geist Mono

## Non-goals
Content, search/filters, routing, attribution/CC BY, entry text — unchanged.
