# 高性价比人生指南 · 阅读站

在线访问：https://siinxu.github.io/how-to-live-better/

这是 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（《高性价比人生指南》）的重新排版阅读站：34 节、677 条建议，可按关键词、章节、证据等级、性价比和成本筛选；另含长文、术语表和核实记录。

- **内容**：条目、长文、核实记录的文字逐字取自原仓库，作者 eternity4719，以 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 发布。本站只改了排版、导航和交叉引用链接，未改动内容。内容以原仓库为准，发现错误请到[原仓库提 issue](https://github.com/eternity4719/HowToLiveBetter/issues)。
- **同步版本**：见站点页脚显示的原仓库提交号。
- **更新数据**：`git clone https://github.com/eternity4719/HowToLiveBetter /tmp/htlb && pip install markdown && python3 tools/build.py /tmp/htlb`，会重新生成 `data/`。
- **视觉（v2）**：**Clarity Docs** — 参考 Refero（衬线编辑风 + 纸质画布）、Beautiful UI（编号 mono 标签 + 细线）、Linear（克制无光晕）、Mobbin（柔和底板）。刻意不用 UI Resource Hub 的近黑+电青。详见 [DESIGN.md](./DESIGN.md)。纯静态，无后端。

## 多语言 / Languages

界面支持 简体中文、繁體中文、English、日本語、한국어、Bahasa Melayu、Tiếng Việt、Français、Español、Deutsch（右上角切换，记住选择；首次按浏览器语言/时区自动选择，也可用 `?lang=en`）。

- 繁體中文：全部内容由简体原文经 OpenCC（s2tw）转换字形。
- English / Español：条目标题、说人话、成本、收益、备注和章节导读来自 [dlgrv/HowToLiveBetter](https://github.com/dlgrv/HowToLiveBetter) 的非官方译本（Unlicense），只采用中文原文与本站同步版本一致的字段；来源引用不翻译。
- 其他语言：界面、筛选、章节标题已翻译，条目正文保留中文原文。
- 生成脚本见 `tools/i18n/`。
